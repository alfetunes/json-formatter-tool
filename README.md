# JSON Formatter

A lightweight, privacy-focused JSON formatting tool that runs entirely in the browser.

No data is sent to external servers, making it suitable for working with sensitive JSON files in secure environments.

## Features

- ✅ Pretty print JSON
- ✅ Minify JSON
- ✅ Validate JSON syntax
- ✅ Syntax highlighting
- ✅ Copy formatted JSON to clipboard
- ✅ Download formatted JSON
- ✅ Open local JSON files
- ✅ Clear input and output
- ✅ 100% client-side
- ✅ No external libraries
- ✅ No internet connection required

## Privacy

This application processes everything locally inside your browser.

- No backend
- No API calls
- No analytics
- No tracking
- No cloud services

Your JSON never leaves your computer.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

No frameworks or third-party dependencies are used.

## How to Use

1. Open `index.html` in your browser.
2. Paste your JSON into the input panel or open a local JSON file.
3. Choose one of the available actions:
   - **Pretty** – Format and indent the JSON.
   - **Minify** – Remove unnecessary whitespace.
   - **Validate** – Verify that the JSON is valid.
   - **Copy** – Copy the output to the clipboard.
   - **Download** – Save the formatted JSON as a file.
   - **Clear** – Clear both input and output panels.

## Security

The project includes a restrictive Content Security Policy (CSP) to help prevent unexpected external communication.

The application is designed to work completely offline.
